Plain Workflows Publisher

Plain Workflows Publisher is an internal tool used only by the owner of the YouTube channel Plain Workflows. It uploads the channel's own tutorial videos, thumbnails and captions to that same channel through the YouTube Data API.

What it does

  • Uploads a finished video file with its title, description and tags.
  • Sets the video thumbnail.
  • Uploads the English caption track.
  • Reads the upload status of the video it just uploaded.

Who uses it

Only the channel owner. There is no sign up, no public user interface and no access by third parties. It does not read, store or analyze data from any other channel or viewer.

This tool uses YouTube API Services. See the YouTube Terms of Service.
