Privacy Policy

Last updated: October 7, 2026.

Plain Workflows Publisher uses YouTube API Services. By using it you are also bound by the Google Privacy Policy.

Data accessed

The tool is used only by the owner of the Plain Workflows channel. With the owner's authorization (OAuth 2.0), it accesses that channel to upload videos, thumbnails and captions, and to read the status of those uploads. It does not access data of any other user, channel or viewer.

Data stored

The only stored item is the owner's OAuth token, kept on the owner's private server with restricted file permissions. No API data is sold, shared or used for advertising. Upload status responses are kept only as a local log of what was published.

Revoking access

The owner can revoke access at any time at Google security settings. Stored tokens are deleted when access is revoked or the tool is retired.

Contact

Through the Plain Workflows channel.
